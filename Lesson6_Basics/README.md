# 🌱 Урок 6. Основы C шаг за шагом

Это спокойный урок без графики: всё в консоли, с цветами и подсказками.
**Писать программы с нуля не нужно.** В каждом задании правится всего одна строка.

Запусти **BasicsLab.exe**. В меню четыре пункта:

| Пункт | Что делает |
|---|---|
| **1. Проверить задания** | проверяет `src/tasks.c` и показывает, какое задание следующее: теория, пример, схема памяти и что получилось |
| **2. Викторина** | «Угадай, что напечатает»: читаешь кусочек кода и выбираешь ответ 1–4. Писать ничего не надо |
| **3. Шпаргалка** | все основы на одном экране |
| **4. Карточка задания** | открыть любое задание по номеру |

## Как делать задания
1. Открой `src/tasks.c`.
2. Найди строку с пометкой `???` — она всегда одна на задание.
3. Поправь её, нажми `Ctrl+Shift+B` и запусти программу → пункт 1.
4. Галочка ✔ — готово, крестик ✘ — программа скажет, что ожидала и что получила.

Не обязательно делать всё подряд за один раз: хоть по 3–4 задания за вечер.

## Что внутри
| Тема | Задания |
|---|---|
| Переменные и функции | 1–3: сумма, среднее (деление!), чётность |
| Циклы | 4–5: сумма до n, сколько раз буква в строке |
| Указатели | 6–8: обнулить по адресу, swap, адрес большего |
| Массивы | 9–11: сумма, поиск индекса, максимум |
| Строки | 12: длина строки и `'\0'` |
| Стек и куча | 13–15: `malloc`, `calloc`, `free` |
| Структуры | 16–17: `.` и `->`, кот в куче |
| `void*` и типы | 18–19: прочитать `int` и `double` через `void*` |
| Простые алгоритмы | 20–21: развернуть массив, сортировка пузырьком |

Если программа вдруг напишет «программа упала: обращение к чужой памяти» — это не страшно, она не закроется. Значит, где-то указатель смотрит не туда (например, `NULL`).
