# 🧬 Урок 5. Игра «Жизнь»

Клетки на поле живут по трём правилам:
- живая клетка с **2 или 3** живыми соседями живёт дальше;
- мёртвая клетка ровно с **3** соседями оживает;
- все остальные умирают (от одиночества или тесноты).

Из этих правил получаются планеры, корабли и даже «ружья», которые стреляют планерами.

**Писать почти ничего не нужно.** В файле `src/tickets.c` 4 функции, в каждой спрятан баг. Найди его и поправь одну-две строки.
Делай **по порядку**: следующие функции пользуются предыдущими.

**Как работать:** запусти **LifeLab.exe** → посмотри сцену → найди баг в `tickets.c` → `Ctrl+Shift+B` → проверь.
Внизу каждой сцены плашки **«Задания: 1 2 3 4»**: зелёная — починено, красная — ещё нет.
Сцены переключаются клавишами **1–5**, `F2` меняет оформление. Демо: `D`, дальше `N` / `A` / `F` / `X`, как раньше.

---

## Как поле лежит в памяти

```c
typedef struct {
    int            w, h;    // ширина и высота
    unsigned char* cur;     // текущее поколение: w * h байт, 1 — живая, 0 — мёртвая
    unsigned char* next;    // сюда считаем следующее
} Grid;
```

Двумерного массива нет: все клетки лежат **одной строкой**, ряд за рядом.
Сначала весь ряд `y = 0`, потом весь ряд `y = 1`, и так далее.

## Сцены и задания

### 1. Клетки — задание 1, `cell_index`
Кликай по клеткам. Справа — та же память одной строкой; полосы одного цвета — один ряд поля.
**Симптом:** кликаешь в одну клетку — загорается другая.
`D` — как ряды лежат в памяти, по шагам.
**Подсказка:** сколько клеток надо пропустить, чтобы дойти до начала ряда `y`?

### 2. Соседи — задание 2, `count_neighbors`
В каждой клетке цифра — сколько соседей насчитала твоя функция. Красные — где она ошиблась.
Поле замкнуто, как бублик: левый сосед клетки у левого края — клетка у правого края.
**Симптом:** ошибки только у некоторых краёв.
`D` на клетке у края — подсчёт по одному соседу.
**Вопрос:** чему в C равно `(-1) % 12`? Проверь в демо.

### 3. Шаг — задание 3, `life_step`
`S` — один шаг твоей функции, `ПРОБЕЛ` — пуск. Справа два блока памяти и указатели `g->cur`, `g->next`.
**Симптом:** поле мигает, планер разваливается.
`D` — правильный шаг по рядам: читаем из `cur`, пишем в `next`, в конце меняем указатели.
**Вопрос:** что будет, если менять клетки прямо в `cur`, пока соседи ещё не досчитаны?

### 4. Размер — задание 4, `grid_resize`
Тяни ползунки `w` и `h` — поле поменяет размер через твою функцию. Следи за панелью «Куча».
**Симптом:** после каждого изменения в куче на 2 блока больше.
**Вопрос:** куда делись старые `cur` и `next`?

### 5. Галерея — просто играть
Знаменитые узоры: планер, корабль, пульсар, R-пентамино и ружьё Госпера.
Выбери карточку и кликай по полю. `ПКМ` — рисовать клетки, ползунок — скорость.
Когда задания 1–3 починены, поле считает **твоя** `life_step`.
